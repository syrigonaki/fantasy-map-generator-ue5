# Procedural Fantasy Map Generator (UE5 / C++)

A procedural generation tool built in **Unreal Engine 5** using **C++**!

## Progress so far

* **Procedural Terrain Generation (C++):** Uses layered Perlin Noise to generate realistic landmasses and islands. 
* **Political Expansion Simulation:** Generates kingdom borders using a flood-fill algorithm.

## Future Additions

* **Cities and Places of Interest:** Add cities & settlements, along with labels on the map.
* **Kingdom/City Attribute & Border Customization**: Allow the user to modify kingdom/city information & borders.
* **Lasso Tools:** Create a tool that lets the user select a specific area of the map and regenerate it.
* **River Generation:** Simulate water flow from high elevation points down to sea level.
* **Improved UI:** Improve the UI :)
